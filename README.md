# Ready2Go

LINEと連携し、予定・天気・ごみ収集日をまとめて確認／通知できるスマホ向けWebアプリです。

## 主な機能

- 今日の予定・天気・次のごみをまとめるホーム画面
- ホームとは別に開ける「予定」タブと「天気」タブ
- 気温・体感温度・降水確率・湿度・風速・気圧・UV・主要花粉・日の出／日の入・7日間予報
- 予報から作る生活メモ、暑さへの注意目安、気象庁・環境省の公式情報リンク
- 月表示／7日表示カレンダー、繰り返し予定
- 都道府県・市区町村・地区を住所から設定
- 自治体公式情報に基づくごみ収集日と分別検索
- ユーザー別の複数通知時刻、一時停止、前日通知、テスト通知
- オフライン保存、再接続後の同期、JSONバックアップ／復元
- PWA、スマホ向け下部ナビ、ダークモード、文字サイズ変更
- 位置情報とLINE連携の同意画面
- 初回設定ガイドと「明日の準備」画面
- 予定ごとの持ち物チェックリストと天気に合わせた準備案内
- LINEへ文章を送るだけの予定登録（確認後に保存）
- 通知履歴、失敗通知の自動再試行／手動再送、サーバー状態表示
- 招待コード付きテストモード、不具合報告、改善案への投票
- 個人予定を分けたまま使える家族・グループ共有
- 自治体データの有効期限・公式URL・最終確認日の一覧
- ホーム画面に追加した際の「今日・明日・予定・ごみ」ショートカット
- ホーム画面に追加した際の「天気」ショートカット
- ごみ画面を含む全画面で「ホーム・予定・天気・ごみ・設定」の5項目メニューを統一
- 風速をm/s・km/h・体感しやすい強さの目安で表示
- 暑さ表示を今日の最高体感温度による参考案内に修正し、公式警戒アラートと区別
- 選択した市区町村を座標化した天気取得と、地域ごとに分離した天気キャッシュ
- 通知の一括オン・オフ、ログイン期限切れ案内、グループ退出／削除、アカウント削除
- 町田市地区1（忠生・玉川学園・金森の対象丁目）の公式日程を2027年9月まで内蔵
- 入力値検査、API回数制限、セキュリティヘッダー、APIを除外した安全なPWAキャッシュ

## ローカル起動

Node.js 20以上で実行します。

```bash
npm ci
cp .env.example .env
npm start
```

ブラウザで `http://localhost:3000` を開きます。LINE連携機能にはLINE Developersの設定が必要です。

変更後の一括検査は次で実行できます。

```bash
npm run check
```

## 公開

RenderとLINE公式アカウントへの詳しい設定は [DEPLOY-RENDER-LINE.md](DEPLOY-RENDER-LINE.md) を上から順に進めてください。`render.yaml` も同梱しています。

## データベース

- `DATABASE_URL`あり: PostgreSQLへ保存
- `DATABASE_URL`なし: 開発用の`data.json`へ保存
- PostgreSQLへの初回接続時、既存の`data.json`があれば自動的に取り込みます。
- `/health`の`storage`が`postgresql`ならDB接続中、`file`ならファイル保存です。

接続方法と注意点は [DATABASE-SETUP.md](DATABASE-SETUP.md) を確認してください。

## 公開前テストモード

Renderの環境変数で`TEST_MODE=true`、`TEST_INVITE_CODE=任意の招待コード`を設定すると、招待コードを知っているテスターだけがアプリのデータへアクセスできます。通常利用では`TEST_MODE=false`のままにします。

## 大切な注意

- `.env`、チャネルシークレット、アクセストークン、APIキーはGitHubへ登録しないでください。
- `DATABASE_URL`を設定するとPostgreSQLへ保存し、未設定時は開発用の`data.json`へ保存します。
- ごみ収集日や祝日変更は自治体公式ページでも確認してください。
- `OPERATOR_NAME`と`CONTACT_EMAIL`を設定し、プライバシーポリシーと利用規約を実際の運用に合わせて最終確認してください。
- Render Free Web Serviceは停止中に定時通知を実行できません。本番通知には常時稼働するサービス設定が必要です。
